# offAice 原版 vs. AI Room Native — 功能對照

評估原則：**已實作**表示有對應實際程式碼且完成核心測試；**部分**表示流程可用但缺原版完整能力；**未完成**表示沒有可操作後端。「尚缺／限制」欄會註明哪些已在 Apple Silicon Mac 上實際跑過、哪些只有單元測試。

## 建議的 macOS 人工驗收

1. 原有 `state.aesgcm` 仍可開啟，舊專案、對話、設定完整。
2. 新建一個茶歇室，選 Claude＋Codex，開始直播 4–6 輪。第二位必須引用第一位真正完成的發言。
3. 插入觀眾留言，下一位 AI 必須能看見該暱稱與訊息；停止後不再觸發請求。重啟 App 不會自動恢復直播。
4. 排程每日提醒、排程房間訊息各測一次；App 關閉後不補發過去的任務。
5. 圓桌產生兩份成功回答，執行互評；手動採用候選並帶回尚未開始的專案，確認不自動寫檔。
6. 新專案經過討論、選負責人、提案、手動核准、副本執行、Claude 審查、人工確認後才寫回。
7. 核對實際配額下降與 CLI 取消結果；高額度開銷前先縮短輪數與間隔做小規模測試。
