# AIROOM Native（Windows）

Windows 原生版，規劃中，目前還沒有程式碼。

- 產品介紹與原出處：見[根目錄的 README](../README.md)。
- 要做出的功能：以 [docs/FEATURE_PARITY.md](../docs/FEATURE_PARITY.md) 為準，行為和 macOS 版一致。
- 送給模型的提示詞：[docs/PROMPTS.md](../docs/PROMPTS.md)。兩個平台應送出相同的內容。
- 發版：tag 用 `windows-v<版本>`，而且不能標成 Latest，原因見 [docs/RELEASING.md](../docs/RELEASING.md)。

技術選型（例如 WinUI 3／.NET）決定後，建置方式、腳本和這個目錄自己的 `.gitignore` 再補上。
